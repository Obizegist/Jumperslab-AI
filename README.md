# 🏃‍♂️ JumpersLab AI — Análisis Biomecánico de Salto

Motor universal desarrollado en Python, OpenCV, MediaPipe y Streamlit para la evaluación cinemática y biomecánica de saltos horizontales (Salto Largo y proximamente Salto Triple).

## 🚀 Características Principales
- Detección automática y precisa de fases (Touchdown / Apoyo, Toe-Off / Despegue y Aterrizaje).
- Cálculo de velocidad de salida, ángulo de trayectoria, tiempo de contacto y parábola de vuelo.
- Diagnóstico técnico con semáforos y puntuación global basada en rangos biomecánicos óptimos (Flexión máxima de rodilla, ángulo inter-rodillas, ángulo de ataque).
- Auditoría de fiabilidad física basada en la aceleración de gravedad 

## 🛠️ Tecnologías Usadas
- Python / Streamlit
- Google MediaPipe (Pose Landmarker)
- OpenCV / NumPy / Matplotlib
